# TCGA-BRCA research data, privacy and model-use policy

Authored by Paul Skeffington · Compiled with OpenAI

**Scope:** The Cancer Genome Atlas breast invasive carcinoma project (`TCGA-BRCA`) through the National Cancer Institute Genomic Data Commons (GDC). This policy applies to Paul's Notes code, AI-assisted experiments, Rust/Python exports, CI evidence, documentation, and any model or chart derived from the project. "PPI" in this work order is treated as PII/PHI or otherwise protected participant information.

## Access gate: only data independently confirmed as OPEN

A file belongs to TCGA **does not mean** it is unrestricted. The GDC designates some files `open` and others `controlled`. The [official GDC access guide](https://gdc.cancer.gov/access-data/data-access-processes-and-tools) explains the distinction, and [GDC analysis policy](https://gdc.cancer.gov/analyze-data/data-analysis-policies) forbids reidentification attempts even for open data.

* Allowed for future approved research: GDC files whose **current official metadata** explicitly says `access=open`, whose case project is solely `TCGA-BRCA`, and whose file type is on the reviewed allowlist.
* Deny by default: `controlled`, unknown access, unverified third-party mirrors, dbGaP-authenticated files, raw read/genotype files, other projects, and any file with direct personal information.
* Use `gdc_open_access_preflight.py` for official **metadata-only** admission checks. This does not download data or authorize a study model; current `research_runner.py` remains synthetic-only.
* Keep download manifests, clinical/biospecimen archives, expression matrices and individual-level outputs **outside Git and external AI prompts**. Do not copy data to telemetry, paste case identifiers into issue/PR logs, or transmit sample-level data to third-party AI services without a separate approved policy.
* Public GDC case/sample barcodes are *pseudonymous linkage keys*, not evidence of identifiable names; nevertheless, do not publish them in this repository's row-level CSV/JSON or model outputs. Aggregate results and verified synthetic fixtures can be published after review.
* Open-access classification, ignore patterns and regex-based scanners do **not** guarantee zero reidentification or confidentiality risk. Handle rare-feature combinations, quasi-identifiers, membership risks and model weights as potentially sensitive. An independent privacy review is required before distributing real-data predictions or trained weights.

## Research-only model disclaimer

> **RESEARCH AND EDUCATIONAL USE ONLY. NOT FOR CLINICAL USE.** Models and visualizations in Paul's Notes are experimental methodological demonstrations. They are not validated medical devices, diagnostic tests, clinical decision-support systems or individualized prognosis/therapy tools. Do not use any score to diagnose cancer, infer recurrence or survival for an individual, choose treatment, screen patients, or replace professional clinical judgment. Model performance on engineered synthetic observations or a limited public TCGA cohort does not establish generalization, clinical benefit, causation or equitable performance across populations.

Every published model card/report must identify its exact target, specimen/case unit, dataset and GDC release/verified file metadata, preprocessing, grouped splits, feature-selection scope, class definitions, evaluation denominator, calibration/uncertainty status, limitations, external validation status and source revision. If these are missing, mark the result **exploratory / not clinically validated** rather than presenting a validated estimate. No identifier-bearing predictions or raw rows should be pushed to GitHub. Rust inference artifacts require the same review as Python output.

## Attribution and reuse

The official [NCI TCGA citing guide](https://www.cancer.gov/ccg/research/genome-sequencing/tcga/using-tcga-data/citing) requests an acknowledgment of the TCGA Research Network in research reports and presentations. Use the following standard acknowledgment when TCGA-derived results are actually reported:

> The results published or shown here are in whole or part based upon data generated by the TCGA Research Network: https://www.cancer.gov/tcga.

Also name the **specific TCGA-BRCA files/cohort and GDC source**, access date, relevant file metadata/release, transformations and any relevant accession in the reproducibility record. For GDC platform citation see [Heath et al., Nature Genetics (2021)](https://doi.org/10.1038/s41588-021-00791-5).

Synthetic-only demonstrations must not imply that TCGA participants were processed: label them `SYNTHETIC` and include the disclaimer but **do not** claim real TCGA-derived results.

## Enforcement and limitations

* `.gitignore` excludes common downloaded datasets, archives, model weights, credentials and output directories; this is **not** a security boundary against forced adds.
* `scripts/check_public_data_boundaries.py --tracked` checks all tracked paths for blocked file types and heuristic identifier/credential patterns. `--staged` scans staged blobs. CI should run the guard for **every PR**, and its named check should be required for merging.
* To enable the optional local guard: `git config core.hooksPath .githooks`. Git hooks can be bypassed; CI, review, repository permissions and credential scanning remain necessary.
* The guard does not review Git history, reliably deidentify arbitrary free text/images, or prove that an open-access file is intrinsically non-identifying. Any suspected historic exposure requires incident review, credential rotation if applicable, assessment of prior clones/forks, and an approved remediation plan. Do not assume deleting the latest commit removes exposed material.
* The private Dartmouth.HSE R18F/R19 research-admission gates are **not changed** by TCGA's open-access designation. Patient-level prediction and reuse of discovery-selected signatures remain unapproved until separately reviewed.

## Future model-release gate

Before committing any real-TCGA derived aggregate model result: confirm official file access; document consent/access and use terms; independently review the analysis endpoint/units and grouped leakage protections; test small-cell suppression and quasi-identifiers; review prediction disclosure and model inversion/memorization risks; verify no row-level outputs or private source files in staged Git; and obtain the study-specific scientific and privacy signoff. Failure of any check blocks publication, irrespective of model accuracy.
