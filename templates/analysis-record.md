## Triple-block reporting for each numerical finding

Repeat the following three sections for **each** numerical claim (including model fit, plots, statistics, rates, and comparisons). See [reporting contract](../docs/triple-block-analysis-reporting.md). Do not substitute unexecuted example numbers for verified results.

### Block 1 — Method and executable code

- Research question and estimand:
- Independent observation unit and study design:
- Input variables, units, denominator/exposure, missingness:
- Exact named source-code chunk, function or script and arguments:
- Assumptions, software version, random seed and checks:

### Block 2 — Computed numerical result

- Run status: PASS / FAIL / NOT RUN:
- Total N, evaluable n, missing n and event counts:
- Estimates, units, denominator, uncertainty/intervals (where appropriate):
- Executed table/figure/log link, checksum or immutable artifact:
- Reconciliation against computed code output:

### Block 3 — Scientific interpretation

- Direction and magnitude in the measured units:
- Design-dependent interpretation and uncertainty:
- Diagnostics, limitations and alternative explanations:
- Whether findings are descriptive, predictive or causal, with justification:
- Unverified items and next validation gate:
